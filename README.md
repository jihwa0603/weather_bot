# 텔레그램 날씨 봇 프로젝트

이 프로젝트는 파이썬과 텔레그램 Bot API를 활용하여 사용자가 원하는 도시의 현재 날씨를 알려주는 자동화된 봇입니다. 사용자는 텔레그램 채팅창에 간단한 메시지를 입력하는 것만으로도 OpenWeatherMap API를 통해 실시간 날씨 정보를 받아볼 수 있습니다. 이 봇은 파이썬 초급자들이 모듈을 활용하고 외부 API와 연동하는 방법을 배우는 데 매우 훌륭한 예제가 됩니다.

## 주요 기능

* **날씨 조회**: 사용자가 "서울" 또는 "대구"와 같은 도시 이름을 입력하면, 봇은 해당 도시의 현재 날씨 상태, 온도, 습도를 정확하게 알려줍니다.

* **간단한 상호작용**: 사용자는 `/start` 명령어를 입력하여 봇을 시작하거나 봇의 기능에 대한 안내를 받을 수 있습니다. 봇은 사용자에게 친절하고 명확한 응답을 제공하여 자연스러운 대화 경험을 선사합니다.

* **오류 처리**: 도시 이름이 잘못 입력되거나 날씨 데이터를 가져오는 데 실패할 경우, 봇은 사용자에게 오류 메시지를 보내 상황을 설명하고 해결을 돕습니다.

## 사용된 기술

* **Python**: 봇의 핵심 로직을 구현하는 데 사용된 언어입니다. 간결하고 읽기 쉬운 문법 덕분에 초보자도 쉽게 이해하고 코드를 작성할 수 있습니다.

* **`python-telegram-bot`**: 텔레그램 Bot API와 손쉽게 연동하기 위한 파이썬 라이브러리입니다. 이 라이브러리를 사용하면 복잡한 HTTP 요청을 직접 처리할 필요 없이, 텔레그램 봇의 이벤트(메시지 수신, 명령어 입력 등)를 효율적으로 관리할 수 있습니다.

* **`requests`**: 웹 API에 HTTP 요청을 보내고 응답을 받아오는 데 사용되는 표준 라이브러리입니다. `requests` 덕분에 OpenWeatherMap 서버와 통신하여 날씨 데이터를 안정적으로 가져올 수 있습니다.

* **OpenWeatherMap API**: 전 세계 도시의 실시간 날씨 데이터를 무료로 제공하는 웹 서비스입니다. 이 API를 통해 봇은 최신 날씨 정보를 사용자에게 제공합니다. API 사용은 별도의 API 키 발급이 필요하며, 이는 인증 수단으로 사용됩니다.

## 설치 및 실행 방법

### 1. 필수 라이브러리 설치

프로젝트를 실행하기 전에 필요한 모든 외부 라이브러리들을 설치해야 합니다. 다음 명령어를 실행하면 **`requirements.txt`** 파일에 명시된 목록을 바탕으로 모든 의존성 패키지들을 한 번에 설치할 수 있습니다. 이는 개발 환경을 빠르고 효율적으로 구축하는 데 필수적인 과정입니다.  
>`pip install -r requirements.txt`  
### 2. API 키 설정

프로젝트를 정상적으로 실행하려면 두 가지 중요한 API 키가 필요합니다. 이 키들은 코드에 직접 입력하여 사용하게 됩니다.

* **OpenWeatherMap API Key**: [OpenWeatherMap 웹사이트](https://openweathermap.org/)에서 회원가입 후 발급받을 수 있습니다. 발급받은 키를 코드 내의 `OPENWEATHERMAP_API_KEY` 변수에 할당하세요.

* **Telegram Bot Token**: 텔레그램 앱에서 `@BotFather`를 통해 새로운 봇을 생성하면 발급받을 수 있는 고유한 토큰입니다. 이 토큰을 코드의 `TELEGRAM_BOT_TOKEN` 변수에 입력해야 봇이 정상적으로 작동합니다.

### 3. 봇 실행

모든 설정이 완료되면, 터미널(명령 프롬프트)에서 프로젝트 파일이 있는 디렉터리로 이동하여 다음 명령어를 실행합니다.  
>`python weather_project.py`  

명령어가 실행되면 봇이 텔레그램 서버와 연결되고, 메시지를 받을 준비가 됩니다.

## 사용 방법

* **봇 시작**: 텔레그램에서 봇에게 `/start` 명령어를 입력하여 봇과의 대화를 시작하세요.

* **날씨 요청**: "서울" 또는 "대구"와 같이 도시 이름이 포함된 메시지를 입력하면 봇이 해당 도시의 날씨 정보를 찾아 응답합니다.

## FAQ

* **Q: 왜 `requests` 라이브러리를 사용하나요?**
    A: `requests`는 파이썬에서 가장 널리 사용되는 HTTP 라이브러리로, 웹 API에 요청을 보내고 응답을 처리하는 과정을 매우 간단하고 직관적으로 만들어 줍니다. 복잡한 네트워크 통신을 쉽게 처리할 수 있어 개발 효율성을 높여줍니다.

* **Q: `python-telegram-bot` 라이브러리를 사용하면 어떤 점이 좋나요?**
    A: 이 라이브러리는 텔레그램 Bot API와의 상호작용을 추상화하여, 개발자가 직접 복잡한 JSON 데이터나 HTTP POST/GET 요청을 다루지 않아도 됩니다. 대신 `CommandHandler`, `MessageHandler`와 같은 간편한 핸들러를 사용해 봇의 동작을 정의할 수 있습니다.
